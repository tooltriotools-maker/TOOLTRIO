# ToolTrio – Shakespeare Slug / 410 SEO Upgrade

## Final canonical URL

`https://tooltrio.com/fun/insult-generator/shakespeare-insult-generator`

This URL is generated by the dynamic route:

`app/fun/insult-generator/[slug]/page.tsx`

The Shakespeare-specific client remains:

`components/fun/ShakespeareInsultGeneratorClient.tsx`

## Retired Shakespeare URLs – HTTP 410

The following URLs are intentionally gone and are **not redirected**:

- `/fun/shakespeare-insult-generator`
- `/fun/insult-generator/shakespear-insult-generator`
- `/calculators/fun/shakespeare-insult-generator`

Their trailing-slash forms are also normalized and treated as gone by middleware.

`middleware.ts` returns HTTP `410 Gone` with `X-Robots-Tag: noindex, follow` for these paths.

## Legacy /calculators/fun migration

The old `/calculators/fun/*` migration was moved from `next.config.mjs` into middleware so the Shakespeare URL above can be excluded from redirects and return 410.

Other legacy `/calculators/fun/*` URLs still permanently redirect to `/fun/*`.

## Sitemap

`app/sitemap.ts` includes only the canonical Shakespeare URL through `MASTER_TOOL_REGISTRY`:

`/fun/insult-generator/shakespeare-insult-generator`

The retired URLs are not in the sitemap.

## Canonical / robots metadata

The dynamic slug page uses `generateFunToolMetadata()` with:

`/fun/insult-generator/shakespeare-insult-generator`

That produces a self-referencing canonical URL and index/follow robots metadata for the new page.
